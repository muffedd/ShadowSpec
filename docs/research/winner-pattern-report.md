## Decisions

1. One audited fixture, not arbitrary hosted execution.
2. Prepared bad and narrow patches, evaluated live and labeled honestly.
3. Characterization and acceptance tests remain separate.
4. Static blast radius is labeled incomplete around dynamic dispatch.
5. Bob is central through repository-wide role guidance and a documented actor–critic handoff; actual session evidence remains unresolved until a real Bob run exists.
6. Evidence pack and failed bad patch are higher priority than a complex graph visualization.
